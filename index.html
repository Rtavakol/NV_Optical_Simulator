Version 04.1 | Interactive optical model

How to use this simulator

  1. Select the laser entrance surface and move the entrance point using the position slider or yellow marker.
  2. Adjust the horizontal incident direction by dragging the green handle, and use the elevation control for vertical steering.
  3. Change the laser power, beam diameter, NV concentration, and diamond corner-cut angle.
  4. Observe the green beam paths, orange absorption heatmap, and predicted photodiode voltage.
  5. Use the saturation controls to compare linear and intensity-dependent NV absorption.

Green represents pump-light propagation; orange represents absorbed pump power; the yellow marker indicates the entrance point. The numerical model is approximate and is intended for exploring optical trends rather than providing a fully calibrated prediction.
